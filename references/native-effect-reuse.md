# 成熟效果的选择、复用与角色接入

在角色需要火焰、烟雾、爆炸、命中闪光等通用演出时阅读本文件。重点是选择已经成立的素材与运动，再适配当前角色。独特形象可专门生成；动作、绑定和效果按各自需求寻找可复用部分。

## 先看原效果，再决定用哪些部分

从用户已有文件、包内样例或有来源的成品工程中找候选。检查实际可编辑文件与目标 reader，载入后观看原速、关键中间帧和起止阶段。判断画风、轮廓变化、喷流/扩散方向、尺度与视角是否适合当前演出；确认是所需原生工程，代码许可与图像、动作素材的许可分别记录。

原 `.spine`、运行时 `.json/.skel` 和编辑器自有格式分别核实。已有工具支持标准导出，不代表能读取编辑器源项目。先试真实导入入口；当前无匹配 reader 时，说明已测输入与缺口，再选有边界的转换或其他合适源文件。本包的 [3.8 读取器](../scripts/spine38-reader/README.md) 只覆盖已核验的两个实际工程结构，不能把版本号相同当作必然可读。

保留原件与输入哈希，先完成原图、原骨架、原动作的原样播放。随后记录当前任务沿用哪些内容：

| 内容 | 来源和适配方式 |
| --- | --- |
| 独特角色美术 | 用户提供或新生成的主图；拆层、补隐藏面分别记录 |
| 成熟效果素材与动作 | 保留原图、骨架、曲线、附件切换和层序；改色、换皮或局部改动作时说明改变 |
| 组合编排 | 发射接口、方向、整体规模、触发与动作衔接；与原效果创作分开记录 |

## 注册与合并

在新副本接入。骨骼局部点经过父级后才是世界位置；检查旋转、缩放和镜像只计算一次。喷口本身有动画时，从当前原动作姿态计算它的位置，再注册到角色的当前嘴部或其他接口，检查整个有效发射时段。

合并骨架时同步处理骨骼、slot、附件和动画名称，重映射加权网格里的骨骼索引及层序引用。仅给骨骼改名不能完成合并。保留可单独播放的原动作，便于判断差异来自源效果还是组合适配。

看清每个原片段包含什么，再安排启动、持续与收束。某个完整喷射动作已经包含消散时，可以复用其启动段，再进入原循环段和原结束段；不要在效果已消失后突然重启。混合时间、采样率和发射长度由该任务的节奏与播放器决定。

## 混合与验收

先查原 slot blend，再看源 PNG 的 RGB/alpha、straight/PMA 与 canvas 背景合成。黑底灰度图可能本来就供 additive 使用；错误背景合成造成黑框时，修正渲染链路并保留原图。浅底、深底和需要的透明输出分别查看，不能用抠黑代替查明混合约定。

按 [验收](acceptance.md) 分别记录源数据保留、接口几何、真实播放与导出消费。附件、层序等离散切换需检查关键时刻前后；JSON 小数和 float32 的边界差异如实保留。MP4 从确定源逐帧渲染并完整解码，工程源仍是交付主体。

## 已认可案例：死亡之翼与原生火焰

2026-10-22，用户认可 [角色合成与分享 MP4](../examples/deathwing-native-fire/README.md)，并要求将经验纳入 SOP。该例沿用已有龙的美术与身体动作，复用用户提供火焰工程的 43 根骨骼、38 个 slot、39 个附件、5 条动画、444 条轨道和 3,534 个关键帧；加入一个接口骨骼后合计 62 根骨骼、42 个 slot。

可复查的材料：

- [来源与图片哈希](../examples/deathwing-native-fire/source/provenance.json)、[原动作数据](../examples/deathwing-native-fire/source/native-fire.json)。
- [组合脚本](../examples/deathwing-native-fire/scripts/build.mjs)、[任务参数](../examples/deathwing-native-fire/source/rig_spec.json)：动态喷口注册、父级缩放补偿、原片段编排。
- [源保留与接口检查](../examples/deathwing-native-fire/evidence/verification.json)：原 5 条动作、9 张图片保持；361 个身体矩阵样本最大差 0，148 个喷口样本最大位置误差约 3.21e-7。
- [网页实播记录](../examples/deathwing-native-fire/evidence/web-review.json)：启动、持续、扫喷与消散，深浅背景和骨骼显示。
- [MP4 脚本](../examples/deathwing-native-fire/scripts/export_mp4.ts)、[完整解码记录](../examples/deathwing-native-fire/evidence/mp4-export.json)：6 秒、360 帧、1920×1080、60 fps。
- [可携带读取器复现](../validation/spine38-reader-reproduction.json)：两份已测输入与恢复 JSON 的哈希对照。

本例 `headScale=1.35`、喷射长度 1150、0.08 秒混合和 60 Hz 合成采样留在任务参数中，不推广为通用参数。Rigby 解析、网页实播与用户视觉认可已有证据；官方 JSON/binary 逐帧等价、官方编辑器重导入、C++/Skia、手机和游戏接入不能据此宣称通过。火焰源文件未附可核验的商用或再分发许可，许可状态随来源保留。
