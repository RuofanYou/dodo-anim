# 失败案例与适用边界

## 恶魔猎手变身：演出目标与制作路线不匹配

**状态：用户于2026-10-23明确否决并要求停做。此案例不属于已认可作品，不作为成功模板继续复用。**

用户要的是酷炫转身，或全身关节伴随爆发性形态变化的完整变身演出。试作采用固定三分之四视角、普通/恶魔两套材料、局部骨骼摆动、附件切换、长角与展翼。两者在动作内容、空间变化和表演力度上不匹配。

### 具体失败

| 问题 | 这次的表现 | 后续应如何判断 |
| --- | --- | --- |
| 动作目标被降级 | 把转身与全身爆发变形做成固定视角换形、展翼 | 先定义转面范围、关键姿态、体积和轮廓怎样连续变化；不能用更容易制作的动作替换用户目标 |
| 素材路线不成立 | 从独立生成的组件图重新拼身体，比例与站姿漂移；回到原画拆分后仍需补很多被遮挡面 | 保形制作优先拆原画；转面需要的另一侧、背面和体积不能从单张可见面直接假定存在 |
| 局部修复代替主演出 | 长时间处理接缝、权重、隐藏面与采样，主演出的转身、爆发感仍未成立 | 先用粗动作检验用户要看的核心变化；核心表达不成立时停止细化和补丁堆积 |
| 验证范围被误解 | 文件可导出、接触误差小或网格不翻面，只证明局部技术条件 | 先看完整动作是否成立，再看比例、重心、转面、节奏和遮挡；数值不能代替视觉验收 |
| 已有经验没有完整落到实现 | 前期没有完整沿用巫师的原画回叠、共同变形场和实际贴图覆盖检查 | 查阅已认可作品的具体代码和素材，记录本次实际复用的实现，不能仅复述同名原则 |

### 此案例能说明什么

当前工作台已认可的经验集中在固定视角、小幅角色表演、道具开合，以及角色与成熟原生效果的组合。此次失败说明：这条已验证路线不足以直接承担明显转面、全身结构爆发变形的目标。

这不是对Spine全部能力的判定。专业制作的多视图材料、网格变形和附件设计与本次单图拆件流程不同；本工作台尚未验证相应完整能力，不能据格式可导出就宣称已掌握。

### 制作前的判断与停止条件

1. 用可查看的关键姿态和粗动作明确视角变化、形变幅度、发生过程与节奏。骨数和软件名称不能代替这一步。
2. 若目标依赖背面、明显空间转体或大幅拓扑/体积变化，先取得并实际查看匹配的完整成熟工程，或明确具备所需多视图与形变素材；缺少时说明当前路线尚不能交付，不静默改成固定视角换形。
3. 适配成功案例时保留其适用条件。巫师举杖和巨龙摆头的成功，不证明复杂转身变身已经可做。
4. 若补图、权重、检测和架构持续增加，核心动作仍与目标不同，应停止该路线并说明原因。用户要求停做时，立即停止制作和相关后台任务。
5. 被用户否决的作品保持失败状态；局部数值通过、某些素材可用或此前的阶段认可，都不能覆盖最终否决。

成熟能量效果的选材与原动作复用在本次真实发生过，但其成功不代表整段角色演出成功。此案例保留的重点是选型、目标对齐、实现复用和验收边界。
